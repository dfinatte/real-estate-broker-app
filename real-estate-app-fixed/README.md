# Real Estate App - Guia de Instalação 
 
## Como usar o app: 
1. Execute o arquivo start-app.bat 
2. Aguarde abrir no navegador 
3. Instale como app clicando no ícone de instalação (+) 
4. Pronto! App instalado no seu desktop 
 
## Requisitos: 
- Windows 10 ou superior 
- Navegador Chrome ou Edge 
- Conexão com internet (apenas na primeira instalação)
